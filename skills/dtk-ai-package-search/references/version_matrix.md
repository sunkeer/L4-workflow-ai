**注意事项**

- **DAS1.4 不存在**，官方直接从 1.3 跳到 1.5，别在脚本里硬编码连续版本号。
- `DAS1.8.3` / `DAS1.8.4` 不是常规生态包目录，只放 XCompute / XSystems 工具。
- `DAS1.2` 里混有少量 `dtk24041` 文件、`DAS1.6` 里混有少量 `dtk2504` 文件，
  同一 DAS 目录内 DTK 不一定唯一 —— **务必按文件名里的 `dtkXXXX` 二次确认**。
- DTK 版本号写法：`dtk2604` = DTK 26.04，`dtk25041` = DTK 25.04.1（末位是修订号）。
